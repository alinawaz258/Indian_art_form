# Exhibition Image Sources and Attribution

All timeline and map image files are stored locally so the exhibition does not depend on remote hotlinks. The files were downloaded from the Wikimedia Commons file pages listed below and are used with the credit shown in `shared/data/artData.js`. Reuse the files according to the license displayed on each linked file page.
